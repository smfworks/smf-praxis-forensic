# Praxis Forensic

Private forensic-engineering vertical for Praxis. It provides the `forensic` vertical specification, packaged governance knowledge, and authority policy used by engineering-investigation workflows.

## Installation

Install alongside Praxis Agent 0.29.1 or newer:

```bash
pip install praxis-agent>=0.29.1 praxis-forensic
```

The distribution registers itself through the `praxis.verticals` entry-point group. Installing the package makes its vertical specification, pack, and evaluation cases discoverable without an application-side import.

## Governance

Praxis may autonomously read evidence and draft analyses. External communications, representations, and destructive actions remain held for human approval.
